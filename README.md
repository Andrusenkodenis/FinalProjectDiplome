## Проект: Автотесты для https://intershop5.skillbox.ru/

Репозиторий содержит финальный проект с автотестами на Java + Selenium + WebDriverManager + JUnit 4 + Maven.
Тесты проверяют ключевые пользовательские сценарии на демо‑сайте интернет-магазина.

- регистрация нового пользователя;
- авторизация пользователя;
- поиск и просмотр товаров;
- работа каталога;
- добавление товаров в корзину;
- оформление заказа.

Тесты реализованы по архитектуре Page Object Model (POM), что позволяет разделить тестовые сценарии и логику взаимодействия со страницами сайта.

## Стек и зависимости:
- Java 17
- WebDriverManager
- JUnit 4
- Maven

## Структура проекта:
- FinalProjectDiplome/
  - pom.xml - Maven-конфигурация и зависимости проекта
  - pages/
    - HomePage.java - открытие главной страницы, переходы в каталог, авторизация и поиск
    - LoginPage.java - форма входа: ввод логина, пароля и проверка авторизации
    - RegistrationPage.java - регистрация нового пользователя, заполнение полей и отправка формы
    - CatalogPage.java - переход по каталогу, выбор категории и открытие карточек товаров
    - ProductPage.java - карточка товара: просмотр информации и добавление товара в корзину
    - SearchPage.java - поиск товаров по названию и отображение результатов поиска
    - CartPage.java - корзина: изменение количества товаров, удаление позиций и проверка общей стоимости
    - CheckoutPage.java - оформление заказа: заполнение контактных данных, адреса доставки и подтверждение покупки
  - tests/
    - BaseTest.java - базовая настройка WebDriver (создание и закрытие браузера)
    - HomePageTests.java - проверка открытия главной страницы и проверка на наличие основных элементов интерфейса
    - AuthorizationTests.java - тест на успешную или неуспешную авторизацию пользователя
    - RegistrationTests.java - проверка регистрации нового пользователя и валидация обязательных полей
    - CatalogTest.java - проверка работы каталога: отображение товаров в корзине и переход в карточку товара
    - ShoppingCartTest.java - проверка добавление товара в корзину, изменение количества товара и удаление товара
    - CheckoutTest.java - проверка пользовательского сценария: оформление заказа от корзины до подтверждение покупки
   
## Настройки проекта:
- URL тестируемого сайта: https://intershop5.skillbox.ru/
- IntelliJ IDEA 
- Фреймворк: WebDriverManager
- Система сборки: Maven
- Архитектура: Page Object Model

## Запуск тестов
mvn clean test
